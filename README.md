# Token Generator API

## Overview

This project is a FastAPI-based web application developed using GitHub Codespaces and GitHub Copilot.

The application demonstrates:

- FastAPI web application development
- Pydantic request validation
- REST API development
- Random token generation
- SHA256 checksum generation
- Swagger API documentation
- GitHub Copilot assisted development

---

## Features

### Welcome Page

Displays a customized welcome message with participant name.

**Endpoint**

```http
GET /
```

### Generate Token

Generates a pseudo-random token.

**Endpoint**

```http
GET /generate
```

### Generate Checksum

Accepts text input and returns a SHA256 checksum along with a generated token.

**Endpoint**

```http
POST /checksum
```

**Sample Request**

```json
{
  "text": "Hello World"
}
```

**Sample Response**

```json
{
  "text": "Hello World",
  "checksum": "a591a6d40bf420404a011733cfb7b190d62c65bf0bcda32b57b277d9ad9f146e",
  "token": "generated_token"
}
```

```bash
pip install fastapi uvicorn pytest
```

## Running the Application

Start the FastAPI application using Uvicorn:

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Application will be available at:

```text
http://localhost:8000
```

For GitHub Codespaces, use the forwarded URL generated by Codespaces.
